# Config

- game / world / player / obstacles / enemies / navigation / combat / weapons / experience / ui로 나누어 기획 수치를 관리한다. 하나의 거대한 설정 파일로 합치지 않는다.
- HP·기본 공격력은 Player/Enemy, 피해 효과는 combat, 무기 사거리·간격·회전·탄환은 weapons, HP 바·선택 화면은 ui에 둔다.
- 거리·크기는 px, 속도는 px/초, 시간은 초를 기본으로 하고 예외와 배율·면적 단위를 주석으로 명시한다.
- 색상, 감지/대기 거리, 순찰 범위, 스폰 주기·상한 등 튜닝 값은 해당 기능 설정에 둔다. 0/1, 배열 인덱스 등 일반적인 계산 상수까지 설정화하지 않는다.
- 기본 수치 변경과 구조 리팩터링을 구분한다. 월드 크기 변경 시 면적별 개수·스폰 여유·경로 격자 비용도 확인한다.
- 기획 조정이 필요한 값은 별도 요청이 없어도 해당 기능 config에 둔다. 설정은 한 줄에 한 항목씩 작성하고 각 값 옆에 의미·단위·필요한 제약을 주석으로 적는다. 파일 첫 줄의 긴 공통 주석만으로 설명을 대신하지 않는다.
- 경험치의 레벨별 필요량·표 이후 증가 배율·보상 분류별 지급량·흡수·아이콘은 experience, Enemy별 보상 분류는 enemies, 화면 레벨/경험치 바 스타일은 ui에서 관리한다. `maxLevel`은 경험치 표의 마지막 레벨이며 최종 레벨 제한이 아니다.

## 재발 방지 테스트

- 반복문의 진행량·분모인 시뮬레이션 단계, 스폰 주기, 검 판정 각도 간격, 격자 간격, 충돌 이동 단계 등에 0·음수·NaN·Infinity를 넣고, 실행 전에 설정 이름을 포함한 오류로 거부하는지 확인한다. 무한 루프 재현은 외부 시간 제한이 있는 별도 프로세스에서 수행한다.
- 개수는 정수·0 이상, 초기 수는 최대 수 이하, 최소값은 최대값 이하인지 검증한다. Enemy·장애물 개수 0은 비활성화로 동작해야 하며 최소 1로 바뀌지 않아야 한다. 잘못된 설정 처리 방식을 테스트에 명시한다.
- 사거리·검 회전 반경·검 크기·탄환 반지름을 각각 바꿔 실제 타격 가능 범위와 AI 정지 조건의 일관성을 확인한다. 성립하지 않는 조합은 검증 오류 또는 명시적인 보정 정책으로 처리한다.
- 현재 기본값만 고정하는 검사에 의존하지 않고 허용 경계·경계 밖·월드 면적 변경 조합을 확인한다.
