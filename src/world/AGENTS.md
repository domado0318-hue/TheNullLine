# World / Obstacles

- 월드와 벽·격자 표시는 `createWorldView`, 장애물 배치는 `createObstacleLayout`이 담당한다.
- 바닥은 `config/world.ts` 크기이며 벽은 바닥 바깥에 둔다. 카메라는 외곽 벽까지만 표시한다.
- 장애물 수·크기·색상·여유 간격은 `config/obstacles.ts`에서 관리한다. 시작 위치와 통로를 확보하고 서로 겹치지 않게 배치한다.
- 원은 지름, 사각형은 한 변을 size로 사용한다. 공유 충돌에서는 원의 실제 모양을 반영한다.
- Player·Enemy에 서로 다른 충돌 공식을 중복 작성하지 않는다. 배치 반복에는 종료 조건을 둔다.

## 재발 방지 테스트

- 원/사각형 장애물의 변·접선·모서리 직전/접촉/직후를 검사한다. 시야 선분 (1000,1000)→(1120,1000), 원 중심 (1060,980.1)·지름 40은 가로막혀야 한다. 선분 검사 간격 사이의 짧은 교차도 놓치지 않아야 한다.
- 점 시야·탄환 폭·개체 크기를 구분해 실제 도형에 맞는 통과 여부를 검사한다. 기대값은 검사 대상과 같은 샘플링 함수로 계산하지 않는다.
- 장애물 개수 0·여러 고정 난수 시드·월드 크기 변경·배치 공간 부족을 확인한다. 개수·크기·비중첩·Player 통로·중앙 시작 여유·유한 종료를 검사한다.
- 큰 이동량·대각선·월드 가장자리에서도 일반 이동과 밀림이 벽, 원/사각형 장애물, 개체를 관통하지 않는지 확인한다.
