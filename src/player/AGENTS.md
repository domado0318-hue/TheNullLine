# Player

- 입력과 플레이어 표시·이동은 `PlayerController`가 담당한다. 수치는 `config/player.ts`에서 관리한다.
- WASD 동시 입력, 대각선 정규화, 키를 누르는 동안만 이동, 초당 이동 속도를 유지한다.
- 일반 이동으로 월드 바닥 밖으로 나가거나 장애물/Enemy를 통과·밀어내지 않는다. 피격 밀림도 공유 충돌을 지켜 처리한다.
- 자동 공격은 WASD 이동을 중지시키지 않는다. HP/기본 공격력은 Player config, 무기는 weapons config에서 관리한다.
- 충돌은 `world/geometry.ts`를 공유한다. 축별 미끄러짐과 작은 이동 단계로 관통을 방지한다.
- 변경 후 대각선·키 해제·벽·원/사각형 장애물·Enemy와의 접촉을 확인한다.

## 재발 방지 테스트

- 실제 입력 처리에 WASD 단일/복수/반대 방향 입력과 키 해제를 전달한다. 같은 시간 동안 직선·대각선 이동 거리가 같고, 키 해제 후 추가 이동이 없는지 확인한다.
- 검/탄환 자동 공격 중에도 입력 이동 속도가 유지되는지 검사한다. 피격 밀림은 별도 요인으로 구분하고, 밀림 종료 후 이동 복구와 벽·장애물·Enemy 비중첩을 확인한다.
