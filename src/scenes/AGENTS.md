# Scenes

- Scene은 월드·Player·Enemy와 카메라를 생성하고 업데이트를 연결한다. 기능 로직은 해당 폴더에 둔다.
- 1280×720 화면, 중앙 시작, 바닥 외부 벽을 포함한 카메라 경계를 유지한다. 크기는 config에서 읽는다.
- Player 이동 후 Enemy를 갱신하며, 긴 프레임도 작은 단계로 나눠 충돌을 처리한다.
- 각 단계에서 Player 이동 후 카메라 영역을 한 번 계산해 Enemy AI와 CombatSystem에 동일하게 전달한다. 화면 등장 판정은 Player 중심의 고정 거리 대신 월드 경계·카메라 크기·줌을 반영한 영역을 사용한다.
- 무기 선택 이후에만 시뮬레이션한다. 각 단계에서 Player→Enemy AI→전투→사망 제거·경험치 드롭→경험치 흡수 순으로 연결하고 마지막에 몸체·HP 바·무기·경험치 표시를 갱신한다.
- 공격/피격 효과는 CombatSystem이 처리하고, HP 0에서는 정지 후 재시작 UI를 표시한다. Player의 자동 공격으로 입력 이동을 잠그지 않는다.
- Scene 재시작 시 이전 표시 객체나 상태를 재사용하지 않도록 확인한다.
- 사망 제거가 반환한 목록만 경험치 드롭에 전달해 중복 드롭을 막는다. 무기 선택 전/Player 사망 후에는 경험치 흡수도 정지하고, 재시작 시 드롭·레벨·경험치·HUD를 새로 만든다.

## 재발 방지 테스트

- 선택 전에는 시간·이동·스폰·전투가 진행되지 않고, 검/탄환 선택 후 갱신이 시작되는지 실제 연결 흐름을 검사한다.
- 짧은 프레임 반복과 긴 프레임의 분할 갱신 모두에서 충돌·스폰 상한·타이머가 안전한지 확인한다. 시뮬레이션 단계 0은 루프 진입 전에 거부되어야 한다.
- 이동→AI→전투→사망 제거를 함께 실행해 공격 불능 정지·관통·죽은 개체의 공격/표시 잔존을 검사한다. Player 사망 후 정지와 여러 번 재시작 시 상태·이벤트 중복도 확인한다.
