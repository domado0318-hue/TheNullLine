# Experience

- Phaser에 의존하지 않는 ExperienceSystem이 드롭·흡수·경험치·레벨을 관리하고, ExperienceRenderer는 외부 리소스 없이 별을 표시한다. 화면 HUD는 `src/ui/`에서 담당한다.
- 기획 값은 `config/experience.ts`에서 관리한다. 보상 분류(normal1/normal2/normal3/elite/boss)는 Enemy 이동 타입과 분리한다.
- 사망 제거된 Enemy 한 마리당 사망 위치에 아이콘을 한 번 생성한다. 보상 0은 드롭하지 않으며, 처치/흡수 시작 시가 아니라 수집 거리까지 도착했을 때 한 번 지급한다.
- 흡수 반경에 들어오면 Player를 향해 가속하며, 일단 흡수가 시작된 아이콘은 계속 추적한다. 경험치 아이콘은 비물리 객체로 장애물을 통과하며 Player/Enemy 이동 충돌을 바꾸지 않는다.
- 레벨은 1부터 시작한다. 필요량을 소비하고 남는 경험치를 보존하며 한 번에 여러 레벨 상승을 허용한다. 표의 각 값은 해당 레벨→다음 레벨 필요량이다.
- `maxLevel`까지 개별 표를 사용하고 이후에는 마지막 표 값 × 배율^(현재 레벨-maxLevel)을 올림한다. 표 길이·양의 필요량·1 초과 배율·흡수 거리/속도 제약을 검증한다.
- 사망→드롭→흡수→실제 경험치/레벨 변화를 연결해 검사한다. 중복 지급·경계 거리·긴 프레임·연속 레벨 상승·표 경계·0 보상·잘못된 설정·새 게임 초기화를 회귀 테스트에 포함한다.
