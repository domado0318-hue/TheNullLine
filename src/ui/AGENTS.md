# UI

- HP 바·시작 무기 선택·쓰러짐/재시작 표시는 `config/ui.ts`의 크기와 스타일을 사용한다.
- HP 바는 각 개체 상단의 월드 좌표를 따르고, 선택/재시작 화면은 카메라 이동과 독립적인 화면 좌표를 사용한다.
- 카메라의 월드 이동과 화면 UI 좌표를 구분하고, WASD 입력과 기존 화면 표시를 방해하지 않는다.
- 화면에 고정된 메뉴는 버튼이 보이는 위치와 실제 클릭되는 위치가 일치하도록 구현한다.
- 카메라가 월드 중앙이나 가장자리에 있을 때도 버튼이 정상 작동하는지 확인한다.
- 무기 선택 전에는 시뮬레이션을 진행하지 않는다. 재시작 시 무기를 다시 고르고 이전 UI나 이벤트를 남기지 않는다.
- 디버그 정보나 구현 세부 내용을 사용자용 UI에 임의로 노출하지 않는다.
- 레벨과 현재/필요 경험치 바는 화면 좌측 상단에 고정한다. 바 중앙에도 수치를 표시하고, 카메라 이동과 무관하게 유지한다. 표시 값은 ExperienceSystem에서 읽고 UI가 레벨/경험치를 별도로 계산하지 않는다.

## 재발 방지 테스트

- DOM 모형의 이벤트 테스트만으로 클릭 정상 동작을 확정하지 않는다. 실제 브라우저에서 보이는 검/탄환 버튼의 화면 좌표에 포인터를 이동·클릭해 반응과 게임 시작을 각각 확인한다. 프로그램으로 `.click()`만 호출하는 검사는 실제 위치 판정을 대신하지 못한다.
- 카메라 중앙/가장자리, 창 크기 변경, 캔버스 여백·축소, 브라우저 확대/축소 후에도 표시 위치와 클릭 위치가 일치하는지 확인한다.
- 선택은 한 번만 실행되고 메뉴가 사라지며 WASD 입력으로 이어지는지 확인한다. 선택 전 정지, 재시작 후 재선택, 오래된 버튼/이벤트 제거를 검사한다.
- HP 바는 실제 HP 감소·0·최대값과 개체 이동/사망에 맞게 표시되는지 확인한다. 브라우저를 실행하지 못했으면 미검증으로 보고한다.
- 경험치 획득·레벨 상승·여러 레벨 동시 상승·재시작 시 레벨/바/중앙 텍스트가 같은 상태를 표시하는지 확인한다. HUD는 마우스/키보드 입력을 가로채지 않는다.
