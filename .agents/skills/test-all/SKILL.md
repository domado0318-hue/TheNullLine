# Test All

프로젝트에 준비된 전체 테스트를 실행하고 결과를 확인한다.

## 작업 절차

1. AGENTS.md와 프로젝트의 테스트 환경을 확인한다.
2. 프로젝트에 준비된 자동화 테스트를 모두 실행한다.
3. 프로젝트 빌드가 정상적으로 완료되는지 확인한다.
4. 프로젝트에 브라우저 검증 화면이나 수동 검증 절차가 있으면 README와 관련 AGENTS.md를 확인하고, 자동화 테스트와 별도 검증 항목으로 구분한다. 실제 브라우저 확인을 수행하지 않았다면 미검증으로 기록한다.
5. 테스트나 빌드에 실패하면 원인을 확인한다.
6. 전체 결과를 정리하여 사용자에게 보고한다.

## 테스트 결과 형식

### 테스트 결과
- 실행한 테스트
- 성공한 테스트
- 실패한 테스트

### 빌드 결과
빌드 성공 여부와 발생한 오류를 설명한다.

### 발견한 문제
실패한 테스트나 추가 확인이 필요한 문제를 설명한다.

### 최종 의견
프로젝트의 테스트 및 빌드 결과를 종합하여 설명한다.

## 규칙

- 테스트 과정에서 게임 코드를 임의로 수정하지 않는다.
- 실패한 테스트를 임의로 삭제하거나 건너뛰지 않는다.
- 실제로 실행하지 않은 테스트를 성공했다고 보고하지 않는다.
- 자동화 테스트 성공만으로 실제 브라우저의 포인터 입력, 화면 좌표, 렌더링 또는 오디오 재생까지 확인했다고 보고하지 않는다.
- 테스트 환경 문제와 코드 문제를 구분하여 설명한다.
- 문제가 발견되면 수정 방법을 제안하되 직접 수정하지 않는다.
- 테스트가 끝나면 사용자의 다음 지시를 기다린다.
