# Implement Plan

작성된 구현 계획을 바탕으로 실제 코드를 작성한다.

## 작업 절차

1. AGENTS.md와 구현 계획을 확인한다.
2. 계획에 작성된 작업을 순서대로 구현한다.
3. 각 단계가 끝나면 정상적으로 구현되었는지 확인한다.
4. 문제가 발견되면 원인을 확인하고 수정한다.
5. 모든 단계가 끝나면 전체 결과를 확인한다.

## 작업 결과 형식

### 구현 완료 내용
어떤 기능을 구현했는지 설명한다.

### 검증 결과
어떤 방법으로 확인했고 결과가 어땠는지 설명한다.

### 남은 문제
해결하지 못한 문제나 추가 확인이 필요한 사항을 설명한다.

## 규칙

- 기존 계획의 범위 안에서 작업한다.
- 계획에 없는 기능은 임의로 추가하지 않는다.
- 기존 기능이 정상적으로 유지되도록 한다.
- 구현 중 계획의 의도를 유지하는 작은 세부 조정은 진행할 수 있다. 변경 이유와 실제 수정 내용을 결과에 보고한다.
- 목표·요구사항·범위·사용자에게 보이는 동작을 바꾸거나 계획과 다른 접근으로 핵심 요구사항을 해결해야 한다면, 해당 부분에 의존하는 작업은 멈추고 변경 이유와 영향을 설명한 뒤 사용자 확인을 받는다. 확인이 필요 없는 독립 작업은 계속 진행한다.
- Git 커밋은 루트 `AGENTS.md`의 Git 규칙을 따른다.
