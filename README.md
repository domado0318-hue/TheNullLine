# THE NULL LINE

TypeScript · Phaser 3 · Vite로 만든 1280×720 탑다운 생존 액션 게임입니다. 타이틀 → 오프닝 → 직업 선택 → 15스테이지 전투로 진행합니다. 현재 구현과 파일 위치는 이 문서를 기준으로 확인합니다. `docs/`의 기획 제안은 구현 완료 목록이 아닙니다.

## 실행과 검증

Node.js 24 환경에서 개발·테스트합니다. 의존성 설치에는 `npm.cmd ci`를 사용합니다. Vite 실행 조건은 `package.json`의 `engines`, 테스트 실행 기준은 Node.js 24입니다.

```powershell
npm.cmd run dev       # http://127.0.0.1:5173/
npm.cmd test          # 로직·UI 모형·에셋·원본 재현 검사
npm.cmd run build    # TypeScript 검사와 Vite 빌드
npm.cmd run preview  # http://127.0.0.1:4173/
```

WASD로 이동하며 공격은 자동입니다. 오프닝은 클릭·방향키·Enter·Space로 넘기고 Esc로 건너뜁니다. 캐릭터와 레벨업 스킬을 선택하는 동안 전투는 정지합니다. 사망·승리 후 재시작하면 캐릭터 선택부터 다시 시작합니다.

## 현재 게임 구성

- 철도 정비공·신호 기술자·폐기물 운반원은 서로 다른 주무기와 직업별 스킬 20종을 사용합니다. 레벨업마다 후보 3개를 제시하고 Lv.5 MAX 스킬은 제외합니다.
- 유한한 3600×1200 전투 바닥에서 승강장 → 열차 화물칸 → 종착역으로 이동합니다. 15개 배경과 9개 소품을 사용하며 충돌·시야·투사체는 공유 월드 판정을 따릅니다.
- 일반 적 17종·정예 3종·보스 3종을 사용합니다. 일반 스테이지는 3웨이브, 5·10·15스테이지는 보스전입니다. 전투 종료 후 다음 스테이지로 전환합니다.
- 이동 스프라이트는 직업별 5방향×4프레임입니다. 선택창은 정비공 B·기술자 B·운반원 A의 투명 초상화를 사용합니다. 현재 걷기 시트는 보존된 사용본이며 추가 아트 품질 승인을 뜻하지 않습니다.
- 현재 BGM 7개·결과 큐 2개·효과음 55개가 연결되어 있습니다. BGM은 절차적 합성 임시곡이며 최종 음악 승인이나 장시간 청취 검증을 뜻하지 않습니다.

## 파일 배치

| 위치 | 용도 |
| --- | --- |
| `public/assets/` | 현재 게임이 읽는 배포 파일만 보관 |
| `images/players/source/` | 현재 걷기 이미지 패킹용 PNG·좌표 JSON 3쌍 |
| `images/players/portraits/` | 선택창 재추출에 필요한 비교판 원본 3장 |
| `images/fonts/` | WOFF2 제작용 OTF 원본 |
| `images/`의 나머지 폴더 | 현재 채택된 아트의 제작 프롬프트·추출 기록 |
| `scripts/` | 플레이어 패킹·초상화 추출·PNG 판독·오디오 합성 |
| `src/config/` | 기능별 기획 값, 단위는 각 항목 주석 참조 |
| `src/scenes/` | 타이틀·전투 연결 |
| `src/world/` | 현재 PlatformWorld와 공유 충돌·시야 판정 |
| `src/enemies/`, `src/combat/` | 스테이지 적·공격·캐릭터 스킬 |
| `src/player/`, `src/experience/`, `src/ui/`, `src/audio/` | 이동·성장·화면·음향 |
| `tests/` | 자동 회귀 검사와 브라우저 검증 화면 |
| `docs/` | 세계관·직업·성장·전투·오디오 기획 원문 |

`public/assets`에는 `backgrounds`, `props`, `opening`, `players`, `enemies`, `effects`, `ui`, `fonts`, `audio`만 둡니다. `tests/config.test.cjs`가 로딩 설정·아틀라스 링크와 실제 배포 파일을 대조하여 누락과 미사용 파일을 검사합니다.

## 제작 원본과 재현

```powershell
node scripts/pack-player-atlases.cjs
node scripts/extract-selection-portraits.cjs
node scripts/generate-sfx.cjs --check
```

앞의 두 명령은 배포 이미지를 다시 쓰므로 아트 수정 작업에서만 직접 실행합니다. 자동 테스트는 임시 디렉터리에서 실행해 현재 픽셀·아틀라스·추출 기록과 일치하는지 검사합니다. 승인된 `*-walk-source.json`의 좌표를 사용해야 합니다. 옛 좌표 재계산 스크립트와 현재 적을 재현하지 못하는 옛 적 패커는 제거했습니다.

적 이미지의 기준 원본은 `public/assets/enemies/sheet-*.png`와 같은 이름의 JSON입니다. 현재 적과 다른 과거 제작 시트는 보관하지 않습니다. 별도의 패킹 전 원본은 남아 있지 않으며, 현재 아틀라스 자체를 보존합니다. 그 외 배경·소품·타이틀·오프닝도 배포 PNG가 최종 사용본입니다. 자세한 보존 사유는 [이미지 자료 안내](images/README.txt)에 있습니다.

`generate-sfx.cjs`는 현재 WAV를 재현하며, `--check`는 쓰기 없이 검증합니다. `generate-bgm.cjs`는 FFmpeg가 필요하며 현재 임시곡을 생성합니다. 브라우저 검증용 녹음·시안 ZIP·이전 이미지 버전은 보관하지 않습니다.

## 검사 범위와 보류 항목

자동 테스트는 이동·충돌·시야·피해·스킬 성장·웨이브 진행·일시정지·재시작·오디오 수명주기·에셋 경로와 제작 원본 재현을 검사합니다. 예전 무한 월드 구현과 그 전용 원화 검사는 제거했으며, 음수 좌표의 이동·길찾기·투사체·직사각형 충돌 회귀는 `tests/world-geometry.test.cjs`에 유지합니다. 기존 검/탄환·순찰 구현은 공유 로직 회귀 테스트에서 사용합니다.

소품 PNG의 투명 상태는 사용자가 직접 확인했으며, 사용자 요청에 따라 투명 여백·모서리의 알파 자동 검사는 제거했습니다. 소품의 표시 크기·바닥 정렬·충돌 영역·배치 검사는 유지합니다.

UI 자동 모형 검사는 실제 포인터·화면 품질 검증을 대신하지 않습니다. 브라우저 확인은 일반 시작 경로와 `tests/*-browser.html`을 사용하며, 15스테이지 수동 완주·모든 스킬 조합의 장시간 밸런스·기기별 청취 품질은 별도 검증 대상입니다.
