# THE NULL LINE 캐릭터 선택과 스킬 성장 기획

작성일: 2026-10-21 · 상태: 구현 전 기획 초안

철도 정비공, 신호 기술자, 폐기물 운반원을 선택 가능한 캐릭터로 설계한다. 캐릭터마다 시작 전용 무기 1종과 독립적인 레벨업 스킬 20종을 제공한다. 총 60종이며, 각 스킬은 최초 습득을 포함해 다섯 번 선택하면 최대 5레벨이 된다. 아래 수치는 첫 플레이테스트를 위한 제안값이다.

이 기획의 범위는 캐릭터, 전용 무기, 스킬, 레벨업 선택이다. 신규 맵·적·영구 성장·장비 획득·무기 진화·수동 스킬 키는 포함하지 않는다. 기존 기획서의 미등록 시민과 도시 기계라는 세계관을 유지한다.

## 1. 캐릭터 구성

| 철도 정비공 | 회전 절단기 | 무리 가장자리에 접근하고 강한 타격 직후 빠지기 | 근접 다수전과 길 확보 | 원거리 견제와 깊은 포위 | [정비공 기획](철도_정비공_기획.md) |

캐릭터 선택 카드에는 이름, 전용 무기, 고유 특성, 강점과 약점을 표시한다. 선택 후 해당 무기를 장착한 상태로 시작한다. 현재 프로토타입의 검/탄환 선택을 이 흐름으로 대체하는 안이며, 이번 작업에서는 구현하지 않는다. 모든 캐릭터는 추가 공격 입력 없이 이동과 자동 발동만으로 플레이한다.

## 2. 레벨업 선택 흐름

1. 시작 캐릭터 레벨은 1이다. 레벨 2가 될 때 첫 선택 기회를 얻고, 이후 캐릭터 레벨이 오를 때마다 한 번 선택한다.
2. 선택 중에는 이동, 적 AI, 공격, 투사체, 함정, 상태 효과, 스폰 및 모든 전투 타이머를 함께 일시정지한다. 메뉴 조작만 가능하다.
3. 현재 캐릭터의 스킬 20종 중 5레벨 미만인 스킬을 후보로 만든다. 미습득 스킬과 습득 스킬 모두 같은 후보군에 들어간다.
4. 후보에서 서로 다른 스킬 3개를 균등 확률로 비복원 추첨한다. 같은 스킬이 한 화면에 중복 등장하지 않는다. 다른 캐릭터의 스킬은 등장하지 않는다.
5. 하나를 고르면 미습득 스킬은 1레벨, 기존 스킬은 현재 레벨 +1이 된다. 고르지 않은 스킬은 바뀌지 않는다.
6. 적용을 한 번 확정한 후 메뉴를 닫는다. 여러 번 레벨이 올랐다면 선택 기회를 순서대로 처리하고, 매번 갱신된 후보군으로 다시 추첨한다.
7. 대기 중인 선택이 모두 끝나야 전투를 재개한다. 빠른 연속 클릭이나 누르고 있던 키로 다음 선택까지 확정하지 않도록 입력을 분리한다.

선택 카드는 이름, 분류, 현재 레벨과 다음 레벨, 변화하는 값, 핵심 효과를 보여준다. 예: `날 연마 Lv.2 → Lv.3 / 절단기 피해 +30% → +45%`. 미습득은 `신규 Lv.1`, 마지막 강화는 `Lv.4 → Lv.5 MAX`로 표시한다. 선택 화면을 닫았다 다시 열어 추첨을 바꾸는 기능과 재추첨 기능은 두지 않는다.

### 최대 레벨과 후보 부족 처리

- 스킬 최대 레벨은 5이다. **최초 선택 1회 + 중복 선택 4회**이며, 1레벨 습득 후 다섯 번 더 올리는 방식이 아니다.
- 전용 무기와 고유 특성은 시작 지급이고 20종에 포함되지 않는다. 스킬 목록에 있는 무기 강화들은 각각 독립적인 1~5레벨 스킬이다. 전용 무기 자체에 별도 레벨은 두지 않는다.
- 초기안에는 습득 스킬 종류 수 제한을 두지 않는다. 20종 모두 습득 가능하지만, 한 스킬에 집중하면 다른 스킬을 얻을 기회를 쓰는 구조다.
- 후보가 2개면 스킬 2개와 보급 1개, 후보가 1개면 스킬 1개와 보급 2개를 표시한다. 후보가 없으면 보급 3개를 표시한다.
- 보급은 `응급 수리: 최대 HP의 25% 회복`, `임시 보호막: 최대 HP의 20% 보호막을 10초간 부여`, `주변 회수: 800px 안의 경험치 드롭을 흡수 상태로 전환` 순서로 빈 칸을 채운다. 완전히 무효인 보급은 비활성화하지 않고 효과 상태를 설명한다. HP가 가득 차고 회수할 드롭이 없어도 진행할 수 있다.
- 보급은 즉시 소비하는 선택 보상으로 스킬 목록과 레벨을 갖지 않는다. 임시 보호막은 재선택해도 합산하지 않고 같은 양과 지속시간으로 갱신한다. 회수 보급으로 생긴 추가 레벨업은 기존 대기열 뒤에 넣는다.
- 스킬 20종을 모두 5레벨로 만들려면 선택 100회가 필요하다. 보급 없이 성장했다면 캐릭터 레벨 101에서 달성한다. 한 판에 모두 완성하는 것을 목표로 삼지 않으며, 기존 경험치 표는 이 문서 작업에서 변경하지 않는다.

## 3. 수치와 효과의 공통 정의

### 레벨 표 읽는 법

각 표의 1~5레벨 값은 **해당 레벨의 최종 효과**다. 이전 칸의 값과 더하지 않는다. `+10% / +20%`는 2레벨에서 총 +20%이며 +30%가 아니다. `100 / 120px`는 최종 반경을 의미한다. 동일 스킬 중복 선택은 레벨만 올리고 별도의 효과 인스턴스를 추가하지 않는다.

### 피해 계산

- 세 캐릭터의 기본 공격력 A는 24다. 캐릭터마다 지정한 무기 계수와 효과별 계수를 곱해 피해를 계산한다. 기본 치명타는 없다.
- 기본식: `피해 = A × 해당 공격의 계수 × (1 + 해당 공격에 적용되는 피해 증가율의 합) × 대상의 받는 피해 배율`.
- 특정 무기 강화는 그 무기에만 적용한다. `모든 피해`라고 명시한 효과만 무기와 보조 공격 모두에 적용한다. 피해량은 내부에서 소수로 유지하고 표시할 때 반올림한다.
- `A의 40% 피해`는 9.6 피해다. 무기 최종 피해의 40%라는 뜻이 아니다. 별도 명시가 없으면 보조 공격은 전용 무기 피해 강화·연쇄 수·추가 발사 효과를 물려받지 않는다.
- 같은 종류의 받는 피해 증가 상태는 가장 강한 것 하나만 적용하고 재적용 시 시간을 갱신한다. 서로 다른 명칭의 받는 피해 증가도 합산하되 합계 +50%를 상한으로 둔다.
- 처치는 피해를 실제로 준 플레이어에게 한 번만 귀속한다. 사망 시 효과 역시 같은 적에 대해 한 번만 처리한다.

### 시간과 중첩

- 공격 간격 감소율은 해당 공격에 적용되는 값을 더한 뒤 최대 50%까지만 적용한다. `최종 간격 = 기본 간격 × (1 - 감소율)`이다. 명시된 보조 공격의 고정 재사용 시간에는 전용 무기의 간격 감소가 적용되지 않는다.
- 이동 속도 증가율은 합산한다. 피해 감소율은 합산 후 최대 50%다. 상태 이상 둔화는 가장 강한 효과만 적용하고 최대 60%다.
- 지속 피해는 효과마다 지정한 틱 주기로 처리한다. 같은 이름의 장판이 겹쳐도 한 대상에게 가장 강한 하나만 적용한다. 다른 이름의 공격은 함께 피해를 줄 수 있다.
- 밀쳐내기는 지정 거리만큼 이동을 시도하되 기존 벽·장애물·개체 충돌을 지킨다. 둔화는 이동 속도만 줄이고 공격 속도는 바꾸지 않는다.
- 보호막은 HP 피해보다 먼저 소모되며 최대치까지만 회복된다. 서로 다른 보호막이 있으면 남은 시간이 짧은 것부터 소모한다. 별도 명시가 없는 한 보호막에 피해 감소를 적용한 뒤 차감한다.
- 스킬 습득으로 새 자동 공격을 얻으면 첫 발동은 그 공격의 기본 간격 뒤다. 기존 스킬 강화는 발동 타이머를 초기화하거나 즉시 재발동시키지 않는다. 새 간격에 맞춰 남은 시간의 비율을 보존한다.
- 생성된 투사체·함정·장판은 생성 당시 공격 수치를 보존한다. 새 레벨의 수치는 다음 생성부터 반영한다. 캐릭터의 HP·이동·방어 수치는 선택 즉시 바뀐다.
- 최대 HP 증가 시 증가분만큼 현재 HP도 올린다. 사망 상태에서는 회복·처치 보너스가 소생을 일으키지 않는다. 같은 시뮬레이션 단계에서 HP가 0이 됐다면 사망 처리를 우선한다.

### 자동 공격과 이동 판정

- 자동 표적은 화면에 몸체 일부가 보이고 사거리 안이며 장애물에 가리지 않은 살아 있는 적 중 가장 가까운 적이다. 동거리면 생성 순서가 빠른 적을 택한다.
- 범위·거리·반경은 별도 명시가 없으면 중심 사이 거리로 판정한다. 회전 절단날과 투사체는 해당 도형과 대상 몸체의 실제 충돌을 사용한다.
- 연쇄 표적도 같은 화면 조건을 적용하며, 직전 적과 새 적 사이의 시야가 열려 있어야 한다. 한 공격 묶음은 같은 적을 중복 대상으로 삼지 않는다.
- 폭발·주변 공격은 중심에서 대상까지 장애물 시야 검사를 적용한다. 밀쳐내기·흡인 역시 장애물 너머의 적에게 적용하지 않는다. 지형을 부수거나 충돌 규칙을 바꾸지 않는다.
- 이미 생성된 공격은 화면 밖에서도 수명과 충돌 처리를 계속한다. 화면 밖의 공격에서 추가 자동 표적 탐색이 필요한 경우 위 화면 조건을 따른다.
- 이동 거리 충전에는 입력에 따른 실제 이동 거리만 더한다. 벽에 막혀 움직이지 못한 시간, 피격 밀림, 순간 위치 보정은 충전하지 않는다. 메뉴 중에는 충전과 소모 모두 멈춘다.
- 보조 효과가 만든 피해는 또 다른 적중·연쇄·처치 폭발을 재귀적으로 만들지 않는다. HP 감소와 경험치 지급은 정상 처리한다. 각 캐릭터 문서에 지정된 전용 무기의 직접 피해만 발동 조건에 쓴다. `모든 처치`라고 명시한 보상은 보조 피해 처치도 집계한다.
- 정해진 주기마다 발동할 공격에 유효 대상이 없으면 공격을 생성하지 않는다. 재사용 대기는 준비 상태로 유지하며 대상을 찾으면 한 번만 공격한다. 놓친 공격을 일괄 발사하지 않는다.

## 4. 성장 구성과 검증 기준

각 캐릭터는 전용 무기 강화 6종, 자동 보조 공격 4종, 고유 운용 강화 5종, 생존과 수집 5종으로 총 20종이다. 조합 예시는 선택의 방향을 설명하는 것이며 세트 보너스나 선행 스킬 조건은 없다. 단독 습득으로도 기능해야 한다.

첫 검증에서는 동일한 적 구성으로 무강화 상태, 선택 10회, 선택 20회 구간을 비교한다. 피해량뿐 아니라 생존 시간, 접근 위험, 이동 경로, 경험치 수집량을 함께 본다. 20종 전체 MAX 상태는 실전 목표가 아니라 중첩 상한과 성능 부하를 확인하는 조건으로 사용한다.

구현 시 확인할 사례는 다음과 같다. 아래 항목은 이번 문서 작성에서 실행한 테스트가 아니다.

- 캐릭터 선택 후 해당 무기·HP·속도·스킬 후보군이 일치하는지 확인한다.
- 신규 습득, 4→5레벨 강화, MAX 후보 제외, 후보 2/1/0개, 한 번에 여러 레벨 상승, 재시작 초기화를 확인한다.
- 카드에는 다음 레벨 값이 보이고 선택 후 실제 효과와 일치해야 한다. 메뉴 중 전투와 모든 효과 시간이 멈춰야 한다.
- 각 캐릭터 20종, 전체 60종의 레벨 표를 검증한다. 선택 100회 후 스킬 레벨이 모두 5이고 6레벨이 생기지 않아야 한다.
- 최대 HP 증가, 보호막 만료, 동일 상태 갱신, 지속 피해 틱, 거리 충전, 함정 개수 상한, 연쇄 재귀 방지를 확인한다.
- 실제 브라우저에서 카드 클릭 위치, 연속 입력 방지, 카메라 이동 중 UI, 이동과 자동 공격, 기존 충돌·스폰·경험치·재시작을 검증한다.

## 5. 현재 프로젝트와의 경계

현재 프로토타입에는 검/탄환 자동 공격과 경험치·레벨 표시가 있고, 캐릭터 선택과 레벨업 스킬 선택은 아직 없다. 정비공은 회전 검의 공격 구조를 출발점으로 삼을 수 있지만, 연쇄 방전·함정·상태 효과·모든 스킬은 별도 구현과 검증이 필요하다.

세부 기획의 수치는 구현 완료나 밸런스 확정값이 아니다. 기존 코드·설정·테스트·AGENTS.md를 수정하지 않고 이 공통 문서와 캐릭터 문서 3개만 추가한다.
