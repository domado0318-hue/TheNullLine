# THE NULL LINE 게임 기획서

> 제목 표기: `THE NULL LINE`은 현재 프로젝트명으로 사용한다. `0호선`은 한국어 제목 후보이며, 둘 다 출시명으로 확정하지 않는다.

## 1. 한눈에 보는 게임

- **장르:** 디스토피아 공포 분위기의 2D 탑다운 생존 액션 로그라이크. 전투의 기본 형식은 Vampire Survivors 계열의 이동과 자동 공격이다.
- **플레이어 상황:** 시민 등록 정보가 말소되어 도시 시스템에 `미등록자`로 감지된다. 도시의 자동화 기계가 플레이어를 오류 또는 폐기 대상으로 처리하려 한다.
- **주요 공간:** 시민이 사라져 철거 대상으로 지정된 `0번 구역`. `0호선` 열차와 폐기 구역의 연결은 대화에서 제안된 방향이다.
- **정서:** 인간을 위한 시설이 정상적으로 작동하는데 인간은 보이지 않는다. 공포는 괴물의 외형보다 안내 방송, 감시 장치, 무심한 행정 문구와 기계의 반복 작업에서 온다.
- **대표 문구:** “이 도시에서 죽음은 끝이 아니다. 재활용의 시작일 뿐이다.” 사용자가 선호한다고 밝힌 문구다. 이야기 속 `재활용`은 도시의 냉혹한 자원 회수 절차를 뜻하며, 인간을 기계 괴물로 개조한다는 설정을 뜻하지 않는다.

## 2. 대화에서 확인된 방향과 아직 열려 있는 부분

| 구분 | 내용 |
| --- | --- |
| 명확히 선호한 방향 | 인간을 재활용해 기계 괴물로 만드는 설정은 덜어낸다. 인간이 사라진 도시에서 기존 기계가 계속 일하는 디스토피아 공포를 살린다. 위 대표 문구와 영어 이름 `THE NULL LINE`에 호감이 있다. |
| 공유 대화에서 정리된 세계관 | 중앙 AI가 시민의 사회적 가치를 평가하고 등록 정보를 삭제한다. 미등록자는 도시의 제거 대상이 된다. 말소된 구역은 `0번 구역`으로 재분류되어 철거된다. |
| 제안된 공간 구조 | 공식 노선도에 없는 `0호선`이 폐기 대상을 운송하고, 열차는 거점, `0번 구역`은 전투 공간으로 쓴다. 사용자가 열차의 정확한 역할이나 한글 제목을 최종 확정하지는 않았다. |
| 검토가 필요한 이름 | `0호선`, `THE NULL LINE`, `NULLLINE`과 유사한 이름의 콘텐츠가 공유 대화에서 언급됐다. 이는 대화의 조사 결과를 기록한 것이며, 상표권·출시 가능성을 이 문서에서 재검증한 결론은 아니다. |

## 3. 세계관 규칙

1. **도시는 인간을 관리한다.** 중앙 AI는 시민마다 사회적 가치를 부여하고, 가치가 없다고 판단한 시민의 등록 정보를 말소한다.
2. **등록되지 않은 존재는 폐기 대상이다.** 등록 기록이 없는 사람은 도시 시스템에서 시민으로 취급되지 않는다. 자동화 기계는 이를 제거해야 할 오류 또는 불필요한 자원으로 인식한다.
3. **도시는 비워진 구역을 철거한다.** 시민이 말소된 지역은 `0번 구역`으로 재분류되고, 철거 기계가 건물과 시설을 해체한다.

도시는 멸망하거나 완전히 고장 난 상태가 아니다. 지하철, 가로등, 청소와 감시 체계가 인간의 부재에도 일상 업무를 반복한다. 이 정상 작동과 인간의 부재 사이의 차이가 이야기의 중심이다. 플레이어가 싸우는 적도 원래 도시의 편의를 위해 만들어진 기계다.

**설정의 경계:** 대화에서 배제한 인간 개조, 생체 실험, 인간을 원료로 한 기계 괴물은 이 기획의 전제가 아니다. `재활용` 문구는 도시가 죽음과 폐기까지 행정 절차로 취급한다는 의미로 사용한다. 구체적인 처리 과정은 아직 정해지지 않았다.

## 4. 플레이 경험

### 핵심 흐름

`폐기 구역 진입 → 이동하며 기계의 접근 회피 → 자동 공격으로 생존 → 처치 보상 획득·성장 → 더 강한 위협에 대응`

이는 현재 구현된 전투와 경험치 루프를 세계관에 연결한 기획 흐름이다. 열차에서 출격하거나 사망 후 열차로 복귀하는 구조는 공유 대화의 **추천안**이며, 구현 및 최종 채택 여부는 별도 결정이 필요하다. 한 판의 목표 시간, 승리 조건, 탈출 방식, 영구 성장 체계도 아직 정해지지 않았다.

### 전투의 읽기 쉬움

- 플레이어는 이동에 집중하고, 선택한 무기는 자동으로 공격한다.
- 적의 실루엣과 공격 방식은 본래 업무와 연결한다. 예를 들어 청소 로봇은 빠른 접근, 감시 드론은 원거리 압박으로 읽히게 한다.
- 공포 연출은 전투 판정을 가리지 않아야 한다. 안내 방송과 감시 카메라 같은 요소는 위험 신호와 플레이어 위치를 파악할 수 있는 화면 정보를 유지하면서 사용한다.

| --- | --- | --- | --- |
| 청소 로봇 | 도시 청결 유지 | 다수 등장, 빠른 접근 | 콘셉트 제안 |
| 감시 드론 | 시민 감시 | 원거리 공격, 추적 | 콘셉트 제안 |

현재 코드는 이름과 외형이 정해지지 않은 **근접 검 적**과 **원거리 탄환 적** 두 종류를 지원한다. 이를 청소 로봇·감시 드론으로 대응시키는 것은 자연스러운 첫 단계이지만 아직 확정된 설정이나 구현 완료 항목이 아니다. 나머지 세 적의 공격, 피해, 생성 규칙은 새로 설계해야 한다.

## 6. 공간과 분위기

### 0번 구역

주 전투 공간 후보. 주민이 사라진 뒤 도시가 철거 순서를 기다리는 장소다. 정상적으로 켜지는 조명, 비어 있는 역사, 반복되는 안내 방송, 플레이어를 따라 회전하는 감시 카메라가 핵심 이미지다. 실제 구역의 지도, 구역 수, 환경 위험 요소는 정해지지 않았다.

### 0호선

공식 노선도에는 없고 폐기 대상으로 분류된 것들을 운송한다는 설정이 제안됐다. 열차가 매 판의 거점이자 게임 제목을 지탱하는 상징적 장소가 될 수 있다. 이 안을 채택한다면 열차에서 폐기 구역으로 출격하는 화면 흐름을 별도 설계한다. 현재 게임에는 열차나 역사, 구역 이동이 없다.

### 텍스트·음향 톤의 예시

공유 대화의 예시 문구를 분위기 기준으로 보관한다. 실제 게임 대사는 확정본이 아니다.

> “현재 구역의 시민 수는 0명입니다.”  
> “미확인 생체 반응이 감지되었습니다.”  
> “청소 절차를 재개합니다.”

공포 표현의 기준은 기계가 악의를 드러내는 연기보다, 정중하고 반복적인 업무 언어로 플레이어를 처리 대상으로 부르는 것이다.

## 8. 다음 기획 결정

1. **제목:** `THE NULL LINE`과 `0호선`을 개발 가제로 계속 쓸지, 새 후보를 만들지 결정한다. 스토어 공개 전에는 관련 게임명과 상표를 별도로 확인한다.
2. **열차의 비중:** 거점/출격 장소로 채택할지, 배경 설정에만 둘지 결정한다. 이 선택이 한 판의 시작·종료 화면을 좌우한다.
3. **한 판의 목표:** 생존 시간, 특정 기계 격파, 구역 탈출 등 종료 조건을 정한다. 공유 대화만으로는 확정할 수 없다.
4. **첫 적의 대응:** 현재 근접·원거리 적을 각각 어떤 기계로 표현할지 결정한다. 기존 전투 판정과 일치하도록 시각 신호를 설계한다.
5. **자원 회수의 표현:** 대표 문구의 의미를 대사와 배경에서 어느 정도 직접적으로 드러낼지 정한다. 인간 개조 설정은 배제한 상태를 유지한다.

## 9. 제작 범위 제안

첫 기획 검증은 현재 프로토타입의 **한 구역, 플레이어, 근접/원거리 기계 적, 자동 공격, 경험치 성장**에 세계관의 시각·음향 톤을 입혀 확인한다. 회수 기계, 진압 병기, 철거 기계와 열차 거점은 각각의 설계가 확정된 후 범위를 잡는다. 구체적인 수치와 일정은 대화에서 정해지지 않아 이 문서에 임의로 넣지 않는다.
